# Logos

> **Read this when** you need the Advanced Telerobotics Research Laboratory's logo for a story, a program, a slide or a partner page, or you want to check that someone used it correctly.

This folder holds six ATR logo files, each as a 3000 px PNG master (transparent background) and a vector SVG. Use the files as they are: never redraw, retype, recolor, stretch or rotate them. The Kent State University wordmark is **not** included; get the official file from [kent.edu/brand/logos](https://www.kent.edu/brand/logos).

- **Which format:** SVG for the web and for print vendors (it scales without blur); the PNG masters for PowerPoint, Keynote, Google Slides, Word and video. Google Slides does not accept SVG.
- **Every file is trimmed tight to the artwork,** so you add the clear space in your layout.
- **Colors:** navy is `#003976` (Kent State Blue, PMS 281 C). The white files are pure white. Print vendors separate the spot color from the SVG; ask for a proof.

## Clear space

X is the height of the roof (the triangle at the top of the mark) in the lockup you are using. Keep at least 1 X of empty space on every side: no text, image edges, other logos, rules or page edges inside it. Also keep every logo at least 0.25 in (24 px) from a trimmed page or slide edge.

| Lockup | X as a share of the lockup's height | X when the lockup is 1 in tall |
|---|---|---|
| Horizontal, horizontal-short | 0.329 | 0.33 in |
| Stacked | 0.236 | 0.24 in |
| Mark | 0.328 | 0.33 in |

Example: a horizontal lockup 4.5 in wide is 1.71 in tall, so X is 0.56 in.

| Lockup | Measured on | Print minimum | Screen minimum |

If a size falls below the minimum, step down: horizontal, then horizontal-short, then the mark (with the lab name as text nearby).

## With the Kent State logo

Lab pieces carry the Kent State logo as a **separate signature**. The two logos are never merged into one lockup.

- **Placement:** ATR at the left or bottom-left; Kent State at the right or bottom-right (or centered). Each keeps its own clear space, and there is no shared divider rule between them.
- **Same band:** if both logos sit in the same header or footer, use the horizontal-short, stacked or mark file for ATR, never the full horizontal (it would name Kent State twice).
- **Kent State's own rules:** keep its ® and its minimum size (use its Stacked file at 1.05 in wide or more), and place it only on a plain area.
- **Never** put the lab's name, a program name or any other text under the Kent State logo, and never build a combined ATR and Kent State logo. Kent State does not allow program-specific versions of its logo.
- **Get the Kent State wordmark** from [kent.edu/brand/logos](https://www.kent.edu/brand/logos). Never use Kent State athletics marks.

## Never

- [ ] Stretch, squash, rotate or re-proportion a logo
- [ ] Recolor it, add outlines, shadows, glows or textures
- [ ] Redraw it, retype the name beside the mark or cut the mark out of a horizontal lockup
- [ ] Place it over a busy photo without a calm area or a navy panel
- [ ] Use it below its minimum size or inside another logo's clear space
- [ ] Call the lab's round emblem a "seal". It is the **roundel** (not included in this pack), so it is never confused with Kent State's official university seal
- [ ] Use a retired lab logo: the old block-letter "ATR" logo (navy A and R with a gold T) or the black interlocking-triangle monogram. Both still appear on the lab website; neither is in this pack, and neither may be used anywhere

## Alt text and approvals

| File | Alt text |
|---|---|
| Horizontal | Advanced Telerobotics Research Laboratory, Department of Computer Science, Kent State University |
| Horizontal-short, stacked, mark | Advanced Telerobotics Research Laboratory (add ", Kent State University" when nothing else on the piece says it) |
| A linked logo | Describe the destination: "Advanced Telerobotics Research Laboratory home" |

> [!IMPORTANT]
> Kent State's brand rules do not say whether a research lab may use its own mark next to university identity. The lab recommends a review by Kent State University Communications and Marketing (UCM) before public use of the ATR mark beside Kent State marks. Merchandise and giveaways with ATR or Kent State marks always need UCM approval and a licensed vendor.
