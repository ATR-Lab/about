# Coverage log

> **Read this when** a story about the Advanced Telerobotics Research Lab appears in the news, on a Kent State channel or on a podcast, or when you report on the lab's outreach.

One row per story, newest first. The log shows reporters what has already been covered and shows the lab which stories led to inquiries or applications. No entries are recorded yet.

## How to fill a row

| Column | What to write |
|---|---|
| Date | Publication date, Kent State style: "Sept. 30, 2026" |
| Outlet | The outlet's name as it writes it, for example "Kent State Today" or "The Kent Stater" |
| Link | The story's URL. If it is paywalled, say so in Notes |
| Reporter | The byline as published |
| Trigger | What led to the story: a paper, an award, an event, a UCM pitch, a reporter's own request |
| Notes | Referral traffic, inquiries or applications that followed; corrections requested; whether UCM was involved |

- Add only stories that exist; never estimate or count media outlets.
- Coverage of TeleBot-1 from 2012 to 2014 predates the lab. Log it only if it is useful as background, dated and attributed to the director's research.
- If a story gets a fact wrong, send UCM the specific error and the source that shows it; UCM asks the outlet for the correction. Note it here.
- Once a month, also check whether AI assistants describe the lab correctly, and note any errors.
